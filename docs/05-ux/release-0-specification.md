# Especificação do Release 0

**Objetivo:** validar a experiência guiada antes da implementação funcional.

## Fluxo

```text
Criar projeto
→ informar origem
→ registrar contexto
→ descrever problema ou oportunidade
→ definir resultado desejado
→ visualizar resumo
→ receber próxima ação
```

## Tela 1 — Boas-vindas

### Conteúdo

- proposta resumida;
- criar novo projeto;
- continuar projeto;
- entender rapidamente o Hydra.

### Mensagem

> Estruture seu projeto de software passo a passo. O Hydra mostrará o que precisa ser definido agora e orientará você durante a jornada.

## Tela 2 — Origem

Pergunta:

> O que deu origem a este projeto?

Opções:

- problema;
- oportunidade;
- solicitação;
- ideia de produto;
- solução já iniciada;
- outro.

## Tela 3 — Contexto

Campos obrigatórios:

- nome provisório;
- descrição;
- trabalho individual ou em equipe;
- nível de experiência;
- estágio atual.

## Tela 4 — Problema ou oportunidade

Campos obrigatórios:

- situação que precisa mudar;
- pessoa ou grupo afetado;
- tratamento atual;
- principal dificuldade.

Campos opcionais:

- evidências;
- consequências;
- hipótese;
- solução imaginada;
- observações.

## Tela 5 — Resultado desejado

Campos obrigatórios:

- mudança esperada;
- beneficiário;
- forma de perceber melhoria.

## Tela 6 — Resumo

Apresenta:

- situação;
- público;
- problema;
- estado atual;
- resultado;
- fatos;
- hipóteses;
- lacunas.

## Tela 7 — Próxima ação

Apresenta:

- uma ação principal;
- motivo;
- instrução;
- exemplo;
- critério de conclusão;
- próxima etapa provável;
- alternativas acessíveis;
- mapa completo disponível.

## Ação de pular

Ao pular:

1. explicar a consequência;
2. permitir continuar;
3. criar pendência;
4. manter a pendência visível;
5. recalcular a próxima ação.

## Saída

- resumo na tela;
- Project Brief;
- lista de hipóteses;
- lista de lacunas;
- pendências;
- próxima ação.

## Fora do Release 0

- autenticação;

- riscos avançados;
- colaboração;
- dashboards.
