# Product Story Map

## Backbone

```text
1. Iniciar
2. Entender a necessidade
3. Definir o produto
4. Estruturar o projeto
5. Planejar a entrega
6. Executar o trabalho
7. Acompanhar e adaptar
8. Validar resultados
9. Encerrar e aprender
```

## 1. Iniciar

- criar projeto;
- informar nome e descrição;
- selecionar origem;
- informar experiência;
- indicar trabalho individual ou em equipe;
- visualizar jornada;
- receber primeira ação.

## 2. Entender a necessidade

- descrever problema ou oportunidade;
- identificar público afetado;
- registrar estado atual;
- registrar dificuldades;
- separar fatos e hipóteses;
- definir resultado esperado;
- descrever consequência de não agir.

## 3. Definir o produto

- definir usuário;
- definir necessidade;
- criar visão;
- registrar benefícios;
- criar objetivos;
- identificar capacidades;
- definir funcionalidades;
- registrar fora do escopo;
- criar critérios de sucesso.

## 4. Estruturar o projeto

- identificar stakeholders;
- definir decisões e responsabilidades;
- registrar premissas;
- registrar restrições;
- identificar riscos;
- avaliar incerteza;
- receber recomendação de abordagem;
- adaptar a recomendação;
- gerar Project Brief ou Charter simplificado.

## 5. Planejar a entrega

- criar backlog;
- vincular itens a objetivos;
- criar histórias;
- definir critérios de aceitação;
- priorizar;
- organizar releases;
- definir primeira entrega;
- decompor atividades;
- registrar responsáveis e dependências;
- estimar esforço;
- definir qualidade e DoD.

## 6. Executar

- visualizar entrega;
- identificar próxima ação;
- alterar status;
- registrar impedimentos;
- consultar critérios;
- marcar como pronto para revisão;
- visualizar progresso.

## 7. Acompanhar e adaptar

- atualizar riscos;
- registrar decisões;
- registrar mudanças;
- analisar impactos;
- ajustar prioridades;
- gerar status;
- visualizar alertas;
- recalcular próximo passo.

## 8. Validar

- revisar itens;
- comparar critérios;
- registrar feedback;
- aprovar ou rejeitar;
- registrar pendências;
- medir resultado;
- alterar backlog;
- definir próxima entrega.

## 9. Encerrar

- verificar objetivos;
- registrar aceite final;
- consolidar resultados;
- registrar pendências;
- realizar retrospectiva;
- consolidar lições;
- gerar encerramento;
- decidir continuidade.

## Capacidades transversais

- motor de próxima ação;
- orientação contextual;
- rastreabilidade;
- flexibilidade controlada;
- progresso e pendências;
- geração de artefatos.
