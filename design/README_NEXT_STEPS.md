# Próximos passos do design

1. Copiar esta pasta `design` para a raiz do repositório Hydra.
2. Revisar `DESIGN_HANDOFF.md`.
3. Fazer commit das referências.
4. Enviar ao Claude Design:
   - quatro telas;
   - logo;
   - documentos canônicos;
   - prompt fornecido.
5. Refinar o protótipo.
6. Exportar as telas finais para `design/approved/`.
7. Registrar as decisões finais no `UX_DESIGN_SPEC.md`.
8. Testar a navegação com pelo menos uma pessoa.
9. Somente depois iniciar o modelo de dados e a escolha de stack.
