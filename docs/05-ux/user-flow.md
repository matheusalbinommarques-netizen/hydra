# Fluxo do Usuário — Release 0

## Fluxo principal

```text
Início
→ Criar projeto
→ Selecionar origem
→ Informar contexto
→ Descrever situação
→ Identificar afetado
→ Descrever estado atual
→ Definir resultado
→ Revisar resumo
→ Receber recomendação
```

## Fluxo de edição

```text
Resumo
→ selecionar seção
→ editar resposta
→ salvar
→ recalcular lacunas
→ recalcular próxima ação
```

## Fluxo de pular

```text
Atividade
→ pular
→ visualizar consequência
→ confirmar
→ criar pendência
→ avançar
→ atualizar recomendação
```

## Regras iniciais do motor

```text
SE nome não informado
    recomendar criar identificação do projeto
SENÃO SE origem não definida
    recomendar definir origem
SENÃO SE situação não descrita
    recomendar descrever problema ou oportunidade
SENÃO SE público afetado não definido
    recomendar identificar usuário ou público
SENÃO SE estado atual não descrito
    recomendar registrar situação atual
SENÃO SE resultado não definido
    recomendar definir resultado desejado
SENÃO
    recomendar criar visão inicial do produto
```

## Componentes permanentes

- mapa da jornada;
- área de trabalho;
- painel contextual;
- resumo do projeto;
- próxima ação;
- pendências.
