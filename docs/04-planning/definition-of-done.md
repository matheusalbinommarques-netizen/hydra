# Definition of Done

Uma história é considerada concluída quando:

- todos os critérios de aceitação foram atendidos;
- o fluxo principal funciona;
- erros previsíveis foram tratados;
- regras críticas possuem testes automatizados;
- os testes passam;
- a interface foi revisada;
- não existe falha crítica conhecida;
- o código é legível;
- decisões relevantes foram documentadas;
- a documentação foi atualizada quando afetada;
- a alteração está versionada no Git;
- a funcionalidade pode ser demonstrada sem manipulação manual de código ou dados.

## Exceção do Release 0

Como o Release 0 é um protótipo de experiência, a conclusão será avaliada por:

- navegação funcional;
- telas representadas;
- conteúdo e estados coerentes;
- possibilidade de avançar, voltar e pular;
- recomendação principal apresentada;
- pendência gerada ao pular;
- roteiro de teste pronto;
- feedback documentado.

Testes automatizados tornam-se obrigatórios a partir do Walking Skeleton.
